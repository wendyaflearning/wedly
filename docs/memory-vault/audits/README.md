# Memory Vault Audits

Ce dossier contient les audits datés du Memory Vault.

Convention de nommage :

```text
YYYY-MM-DD-<scope>.md
```

Exemples :

- `2026-06-28-vendor-onboarding.md`
- `2026-07-15-admin-vendor-lifecycle.md`
- `2026-08-01-full-vault.md`

Un audit ne doit pas seulement vérifier que les fichiers existent. Il doit
comparer le vault, le code, les tests et le comportement attendu.
